# Survey: designing, running and using it

Always offer a survey (intake round 5). The student may skip it; record the decision.

## Design (10-16 questions, about 5 minutes)
1. **Purpose first.** List the 3-4 claims in the report that need primary evidence (problem size, willingness to pay, current practice, satisfaction). Every question must serve one of them; drop the rest.
2. **Sections:** respondent profile (3-4 closed questions), experience of the problem (4-5), reaction to the proposed solution or the research constructs (3-5), one optional open question.
3. **Question rules:** one idea per question; neutral wording (no "Don't you agree..."); closed options that do not overlap and include "Other / Not sure"; 5-point Likert scales labelled at every point for attitudes; amounts as ranges; no personal identifiers (name, phone, email, employer) unless consent is explicit and necessary.
4. **Ethics text at the top:** purpose, that it is for an MBA project at NMIMS CDOE, voluntary, anonymous, about N minutes, can stop any time, data used only in aggregate.
5. **Deliver as paste-ready text** for Google Forms or Microsoft Forms: question, type (multiple choice, checkboxes, linear scale, short answer), options. Save it as `research/survey/form.md` and put it in Appendix A.

## Running it
- Channels the student already has: LinkedIn, WhatsApp or Telegram groups, colleagues, alumni, professional communities. Avoid paying for responses.
- Target 30-50 responses (Research: at least the sample size justified in the methodology). Set a closing date.
- Export responses as CSV to `research/survey/responses.csv`. Never edit raw responses.

## Using it
- Describe it in the method section: dates, channel, sampling (convenience, snowball), number of responses, completion rate, limitations (self-selection, small sample).
- Report counts and percentages with n; charts numbered and captioned; cross-tabs only where n allows. Research projects add the tests chosen in the methodology.
- Put the instrument and summary tables in Appendix A; raw data stays in `research/` (annex only if the guide asks).
- Never round a small sample into a big-sounding claim ("most customers" from 12 replies). Quote the n.

## If skipped
The report relies on secondary evidence and the student's own experience, says so in the method section, and keeps the drafted instrument in Appendix A as the first step of future work.
